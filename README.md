## **1\. Motion-Controlled Need for Speed Controller**

**Components:** Raspberry Pi Pico, MPU6050 Motion Sensor

Turn a Raspberry Pi Pico into a motion-controlled gaming controller! This project uses an MPU6050 accelerometer and gyroscope to detect physical movements and translate them into game controls.

By tilting the controller left or right, you can steer directly in Need for Speed without using a traditional joystick or steering wheel.

It's a fun example of how motion sensors and microcontrollers can be combined to create custom gaming controllers.

## **2\. Wireless Bluetooth Macro Pad with 16 Keys**

**Components:** Raspberry Pi Pico 2 W, MCP23017 I/O Expander, 16 Mechanical Buttons

Build a custom wireless Bluetooth macro pad with 16 programmable keys using the Raspberry Pi Pico 2 W.

The project uses an MCP23017 I/O expander to handle all 16 mechanical buttons while keeping the number of required GPIO connections low. The Pico 2 W communicates with a computer over Bluetooth, allowing the macro pad to send keyboard commands wirelessly.

You can use it for shortcuts, copy and paste, productivity tasks, and custom keyboard functions without needing a USB connection or additional PC software.
